# Variable Conventions

Use UPPER_SNAKE_CASE placeholders such as `{{PRODUCT_NAME}}`, `{{PRODUCT_CATEGORY}}`, `{{PRODUCT_IDENTITY_SPEC}}`, `{{SOURCE_PROMPT}}`, `{{REFERENCE_ASSET_LIST}}`, `{{CREATIVE_DIRECTION}}`, `{{SCENARIO}}`, `{{SHOT_TIMELINE}}`, `{{TOOL_NAME}}`, `{{MODEL_NAME}}`, `{{DURATION}}`, and `{{ASPECT_RATIO}}`. Project-specific resolved values belong in prompt packages/Runs, not silently inside canonical templates.
