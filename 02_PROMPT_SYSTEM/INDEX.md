# Prompt system

Canonical promptها reusable production assetاند. validated default است؛ candidate تا evidence کافی canonical نیست. registry باید با object-level promptها sync باشد.

## Scenario planning
- `PRM-SCN-ARCH-001_v1.0.0.md` — candidate برای Process State Map + duration viability + adaptive Scenario Architecture Menu در 1–4 clips.
- `PRM-SCN-IDEATE-001_v1.0.0.md` — generic scenario ideation.
- `PRM-SCN-CRITIQUE-001_v1.0.0.md` — scenario critique.
- `PRM-SCN-SELECT-001_v1.0.0.md` — selection.

تا زمانی که `PRM-SCN-ARCH-001` روی پروژه‌های بیشتری validate نشده، status آن candidate باقی می‌ماند؛ ولی SOP جدید برای کار scenario-architecture از آن به‌عنوان prompt فعال candidate استفاده می‌کند و evidence بعدی باید به promotion decision منجر شود.
