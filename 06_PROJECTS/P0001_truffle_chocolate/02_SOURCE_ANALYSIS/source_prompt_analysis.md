# P0001 Source Prompt Analysis v1

## Reusable creative DNA
- 10-second timed sequence.
- miniature workers around an oversized food subject.
- macro premium food-commercial language.
- dark minimalist studio environment.
- controlled prop palette.
- consistent character wardrobe/appearance.
- explicit scale relationship.
- smooth cinematic motion and realistic physics.
- final hero reveal with no generated text/logo/watermark.

## KEEP
- timeline-based prompting.
- tiny-worker / giant-food scale contrast.
- premium macro commercial aesthetic.
- lighting continuity.
- environment cleanliness.
- character identity continuity.
- physics/contact instructions.
- clean final hero shot.

## ADAPT
- `tiny chefs` → `tiny chocolatiers` while retaining red-uniform visual identity if approved.
- cheesecake production → truffle finishing, decorating, arranging and gift-box presentation.
- cheesecake cookware/process props → miniature chocolate/decorating/packaging tools.
- giant single dessert → one hero truffle in macro action followed by reveal of the full assortment/box.
- fixed camera rule → one deliberate, physically plausible camera move may be allowed if it improves the 10-second reveal; avoid multiple compound moves.

## REMOVE
- cheesecake, cherries, crust, cream-cheese filling, baking, springform pan, oven sequence and all old-product-specific ingredients/actions.
- any old-product geometry or material logic.

## Conflicts / risks in source template
1. Twelve process beats inside 10 seconds create excessive temporal density for a new generative video task.
2. `camera completely fixed` conflicts with the visual reference/storyboard language if a pullback or reveal is expected; P0001 should choose one explicit camera policy rather than inherit both.
3. The style/storyboard reference contains the old cheesecake product and must never be used as product-identity authority.
4. Many simultaneous miniature characters/actions increase duplication, anatomy and continuity risk.
5. Literal reuse of old tools/process would contaminate the truffle category.

## P0001 adaptation rule
Reduce the 10-second story to approximately three major beats: hero-truffle hook → controlled miniature finishing/arrangement → full kraft-box hero reveal. Preserve the source prompt's visual grammar, not its old dessert content.
