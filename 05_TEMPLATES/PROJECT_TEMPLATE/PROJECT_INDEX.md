# Project Index

## Quick context order
A new AI/session should read this project in this order:
1. `STATUS.md`
2. `HANDOFF.md`
3. `project.json`
4. current-stage documents linked from the handoff
5. only then deeper Run/prompt/evidence files as needed

## Project structure
- `00_BRIEF/` — deliverable and constraints
- `01_INPUTS/` — immutable original inputs and source prompt
- `02_SOURCE_ANALYSIS/` — source prompt reverse engineering
- `03_PRODUCT_IDENTITY/` — identity spec/lock/uncertainty
- `04_REFERENCE_STRATEGY/` — reference plan and roles
- `05_REFERENCE_ASSETS/` — original/cleaned/generated/approved references
- `06_CREATIVE_DIRECTION/`
- `07_SCENARIOS/`
- `08_SHOT_DESIGN/`
- `09_STORYBOARD/`
- `10_KEYFRAMES/`
- `11_PROMPT_PACKAGES/`
- `12_RUNS/` — every meaningful AI execution
- `13_EVALUATION/`
- `14_REPAIRS/`
- `15_FINAL/`
- `16_POSTMORTEM/`
- `17_LEARNINGS/`
- `18_CONVERSATION_LOG/` — durable feedback/session summaries
- `19_HANDOFF_ASSETS/` — optional safe previews for cross-chat continuity

`HANDOFF.md` must always point to the files that matter now so the next session does not need to inspect every directory.
