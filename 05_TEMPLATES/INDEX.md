# Templates

قالب‌ها scaffold هستند؛ پس از ایجاد object-level فایل پروژه/Run حقیقت است.

## Scenario planning
- `SCENARIO_MENU_TEMPLATE.md` — Process State Map، capacity، duration viability و scenario cards.

## Multi-clip
- `MULTI_CLIP_SEQUENCE_TEMPLATE/MASTER_SEQUENCE.md` — master story/identity/boundary/reference/assembly plan.
- `MULTI_CLIP_SEQUENCE_TEMPLATE/CLIP_CONTRACT.md` — start state، action arc، end state، references و QA برای هر clip.

## Existing templates
Project, Run, Prompt, Experiment, Benchmark, Observation, Hypothesis, Learning, Change Proposal, Decision Record, Tool Card و Postmortem templateها همچنان استفاده می‌شوند.
