# CHK — New Chat Context Load

Use at the beginning of a new ChatGPT/AI session when this repo is the project memory.

- [ ] Read `AI_START_HERE.md`.
- [ ] Read `AGENTS.md`, `START_HERE.md`, `DASHBOARD.md` and `00_SYSTEM/INDEX.md`.
- [ ] Identify active project(s) from registry/index.
- [ ] If one project is active, read its `STATUS.md`, `HANDOFF.md`, `project.json`.
- [ ] Confirm current stage and next action.
- [ ] Load only current-stage SOP/checklist/prompt/tool/learning files.
- [ ] Check whether any required visual asset is unavailable for inspection.
- [ ] If unavailable, request only the exact asset that must be re-attached.
- [ ] Do not ask the user to repeat chat history already represented in repo.
- [ ] Give a concise Context Snapshot before or while continuing work.

## Pass condition
AI can state: project ID/title, deliverable, stage, approved items, blocker, exact next action, and required media (if any) without relying on prior chat memory.
