# CHK — Session Handoff

Use before ending a session that materially changed an active project.

- [ ] `STATUS.md` shows the correct current stage.
- [ ] `HANDOFF.md` has a one-paragraph current context.
- [ ] Approved/locked product identity, references, scenario, keyframes and prompt package are listed accurately.
- [ ] Important recent Runs and evaluations are linked.
- [ ] Known failures/risks are recorded.
- [ ] Latest important user feedback/decision is captured.
- [ ] Blockers are explicit.
- [ ] Exact next action is one concrete action or gate.
- [ ] Media that may require re-attach next chat is listed.
- [ ] Important feedback is appended to `18_CONVERSATION_LOG/FEEDBACK_LOG.md`.
- [ ] Material session work is summarized in `18_CONVERSATION_LOG/SESSION_SUMMARIES.md`.
- [ ] Any generalizable insight has the right OBS/HYP/LRN treatment.
- [ ] Prompt/Run/evaluation provenance is complete.
- [ ] Repo changes are committed with a clear message.

## Pass condition
A new AI session can continue the project after reading `AI_START_HERE.md` + project `STATUS.md`/`HANDOFF.md`, with at most a request to re-attach a specific unavailable visual asset.
