# Checklists

Every item is pass, fail, or N/A with rationale. A failed gate blocks progression unless a documented exception is approved.

Key routing:
- `CHK_SCENARIO_ARCHITECTURE_MENU.md` — before scenario/duration/clip architecture selection.
- `CHK_MULTI_CLIP_CONTINUITY.md` — Master Sequence, boundaries, per-clip production, and assembly for 2/3/4 clips.
- Stage-specific checklists cover intake, source analysis, identity, references, storyboard, keyframes, video preflight/QA, repair, final delivery, postmortem, and system changes.
