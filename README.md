# AI Video Ad Lab

سیستم محلی و نسخه‌دار تبدیل تصاویر محصول، پرامپت مرجع و محدودیت‌های خلاقه به تولید قابل‌ردیابی تبلیغ AI است. مخزن تنها آرشیو خروجی نیست: پروژه، Run، پرامپت، ارزیابی، شکست و یادگیری را به دانش پروژهٔ بعدی تبدیل می‌کند.

06_PROJECTS حقیقت پروژه‌ها و هر اجرای AI یک Run با prompt/reference/settings/output/evaluation است. 02_PROMPT_SYSTEM دارایی‌های prompt نسخه‌دار، 07_EXPERIMENTS آزمون کنترل‌شده و 09_LEARNING مسیر evidence تا استانداردند. CSVهای 10_REGISTRY view تولیدشده‌اند.

اصل‌ها و شکست‌ها overwrite نمی‌شوند؛ identity محصول بر style مقدم است؛ task از tool جداست؛ فقط prompt validated پیش‌فرض است. رسانه در پروژه می‌ماند و metadata/hash در Git ثبت می‌شود. شروع: START_HERE.md، نقشه: 00_SYSTEM/INDEX.md، قواعد: AGENTS.md.
