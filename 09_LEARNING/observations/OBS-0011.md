# OBS-0011 — Master-only camera derivation preserved combined-scene continuity better

## Status
`provisional`

## Project
`P0001`

## Observation
For the final wide KF03 derivation, using only the selected combined `R0015` scene master produced stronger spatial continuity than the previous two-reference setup (`R0015 + R0003`).

### Evidence
- v04 with `R0015 + R0003`:
  - `R0018` failed strict trajectory continuity despite strong standalone aesthetics;
  - `R0019` failed and moved all three chefs outside/in front of the box.
- v05 with `R0015` only:
  - `R0020` passed and preserved the central multicolor hero plus same three-chef local region;
  - `R0021` also preserved the core local world, with more assortment drift than R0020.

## Interpretation
A complete, globally coherent product reference can become a stronger composition attractor than a partial scene master when asking an image model to derive a much wider camera state. Removing that competing full-box reference allowed outward scene extrapolation to preserve the already-established local world more successfully.

## Current project implication
When deriving adjacent camera states from a stable combined scene in P0001:
- prefer the scene master alone first;
- add secondary identity references only if a specific identity failure appears;
- avoid filling reference slots by default.

## Confidence
`provisional / strong project-level evidence`

## Do not overgeneralize
This is not yet a universal cross-model or cross-project rule. Validate on future products and tools before promotion to a global SOP.
