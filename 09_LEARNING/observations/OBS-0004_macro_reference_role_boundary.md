# OBS-0004 — Macro reference improves material evidence but can regularize shape

- Date: 2026-08-07
- Project: `P0001`
- Runs: `P0001-R0005`, `P0001-R0006`
- Task: `REF-PROD-MACRO`
- Tool: ChatGPT Image
- Evidence level: project observation

## Observation
Both generated macro candidates gave useful close-range evidence for multicolor nonpareil scale, contact and dark-chocolate material. However, the macro generation still introduced its own large-scale shape/material interpretation: R0006 regularized the truffle toward a cleaner sphere, while R0005 rendered the fluted cup too glossy/translucent.

## Operational implication
A macro reference should be assigned **texture/material authority only** unless direct source evidence proves its geometry. It should not silently override a real product photograph or a higher-fidelity source-preserving identity reference for silhouette, proportions or packaging.

## P0001 decision
- `R0006` selected for texture/material scale.
- Original real photo + `R0003` remain higher authority for handmade geometry and visible product facts.
- Future prompt packages must state reference roles explicitly when combining product images.

## Promotion status
Observation only. Test on additional product categories before converting this into a global canonical rule, although it is immediately active as a safe project-level reference-role constraint.
